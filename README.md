# 👟 Shoes Sport Sales - Análisis Integral de Ventas y Mercado

## 📌 Descripción del Proyecto
Este proyecto presenta un análisis integral del mercado de calzado deportivo, combinando **SQL, Power BI, Web Scraping, Google Trends y Excel**.  
Se construyó una base de datos de ventas y clientes, se integraron múltiples fuentes externas y se desarrolló un dashboard interactivo en Power BI para responder preguntas clave de negocio: **¿dónde abrir una nueva tienda física?, ¿qué stock priorizar? y ¿cómo optimizar el portafolio de productos?**  
El resultado es un caso completo de **Data Analytics end-to-end**, con insights accionables y recomendaciones ejecutivas.

---

## 🎯 Objetivos
- Construir una **base de datos SQL** realista con información de ventas, clientes y productos.
- Integrar datos provenientes de distintas fuentes:
  - **Scraping web** de marcas deportivas para modelos y precios.
  - **Embajadores de marca e influencers**.
  - **Google Trends** para analizar el interés de los consumidores.
  - Archivos Excel complementarios.
- Desarrollar **consultas SQL avanzadas** para generar KPIs y vistas de negocio.
- Crear un **informe interactivo en Power BI** con enfoque en:
  - Evolución de ingresos y pares vendidos.
  - Segmentación de clientes.
  - Análisis de fidelidad y frecuencia de compra.
  - Análisis geográfico de ventas.
  - Rendimiento de marcas y productos.
- Formular **recomendaciones ejecutivas** a partir de los insights generados.

---

## 📊 Alcance del Informe
El dashboard en Power BI incluye las siguientes secciones:

1. **Resumen Ejecutivo**  
   Principales KPIs, ingresos, clientes, ventas por marca y tendencias generales.

2. **Análisis de Ventas**  
   Evolución de ingresos, ticket promedio, estacionalidad y variaciones YoY/YTD.

3. **Clientes y Segmentación**  
   Perfil de clientes, rangos de edad, ticket promedio por segmento y canal.

4. **Lealtad y Frecuencia**  
   Antigüedad de clientes, promedio de días entre compras, compras repetidas.

5. **Marcas y Productos**  
   Top modelos vendidos, participación por marca, lanzamientos recientes vs. antiguos.

6. **Tendencias**  
   Integración con Google Trends para evaluar interés en marcas por región.

7. **Análisis Geográfico**  
   Ventas por país y canal, concentración de clientes y facturación regional.

8. **Recomendaciones Estratégicas**  
   - Apertura de una nueva tienda física en Portugal.  
   - Optimización del portafolio de productos (eliminación de categorías poco rentables).  
   - Estrategias de captación de clientes y rotación de stock.  

---

## 🛠️ Tecnologías y Herramientas Utilizadas
- **SQL Server** → creación de base de datos, consultas de clientes, productos y ventas.  
- **Power BI** → modelado de datos, medidas DAX, visualizaciones interactivas y storytelling.  
- **Excel / CSV** → integración de datos externos (embajadores, precios, scraping, Google Trends).  
- **Web Scraping** → recopilación de precios y modelos de sitios oficiales de marcas deportivas.  
- **IA** → apoyo en la generación inicial de la base SQL para simular datos realistas.
